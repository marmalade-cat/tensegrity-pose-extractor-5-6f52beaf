tensegrity-pose-extractor-5

Prototype: normalize simple module pose data from mixed JSON/CSV into a canonical CSV and visualize it in-browser. No dependencies. Use index.html to load included examples and save normalized CSV.

Notes:
- This is a compact demo, not a production extractor. Replace parsing routines with real dataset-specific logic when you have real files.
- All code client-side; no network calls.

Usage:
- Open index.html in a browser.
- Click example inputs to load, then Normalize and Download CSV.
